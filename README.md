## What DeskHaus Provides

DeskHaus gathers common office tasks into a single, streamlined environment. Write and format documents, build calculation-ready tables, handle spreadsheet data, and edit images using a layered workflow without switching between separate applications.

Built around HTML and JavaScript, DeskHaus works in both web and desktop settings. The single-file application can support offline use without a server or traditional installation, making it suitable for quick document, table, and image work on compatible Windows environments.

## Frequently Asked Questions

### Can DeskHaus run as a web app?

Yes. Use the hosted build in a browser, or download the HTML application file for local use.

### Is a server needed?

No. The single-file workflow runs by opening the HTML application directly in a compatible browser.

### Are Excel and CSV imports supported?

Yes. The table workspace can import Excel and CSV data. Finished tables can be exported to an Excel-compatible format.

### What formats are available for image export?

Images can be exported as PNG, JPG, WebP, ICO, or GIF files.

### Can DeskHaus print documents and make PDFs?

Yes. The document workspace supports both printing and PDF export.

### What if DeskHaus fails to open?

First verify that the browser or desktop runtime is current and compatible. Then download the latest build and open the HTML file again. For local copies, make sure all files distributed with the application remain together.

### How do I get updates?

### Where are DeskHaus settings stored?

The main workflows are managed from the application interface. The single-file edition does not use a separate server configuration file.
